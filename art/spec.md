# 够级 · 美术规格

> 阶段：简洁版（spec 第 1 轮，2026-10-09，guluga-game-art）。正式美术照这份出，美术评审照这份审，界面照这份排版。
> 开工拍板的方向：**A 青岛海边露台（seaside）**，不换。样张：`~/projects/pipeline/games/gouji/assets/sample-a.png`（夜）、`sample-a-day.png`（日）。
> **简洁版**（首发上线用）：`art/simple.py` 按本表的文件名、尺寸、帧数用代码画进 `apps/web/public/art/`，PNG 里带 `tier=simple` 文本标记。`python art/simple.py --check` 核对本表和文件一一对应、尺寸对，并列出哪些还是简洁版；`--preview` 在 `art/out/preview/` 拼出缩放到显示尺寸的预览。正式美术定稿先放 `art/out/final/`（同样的目录结构），换图验收开始时再同名覆盖。
> 路径都相对 `apps/web/public/art/`。「单帧尺寸」是**原始像素**；精灵图横排，文件宽 = 单帧宽 × 帧数。「显示」是界面上的整数倍（1× = 原图大小）。所有像素图 `image-rendering: pixelated`，只按整数倍缩放，**不要旋转非 90° 的角度**（会糊）。
> 牌面不在本表：复用 `apps/web/public/cards-pixel/`（41×57，52 张 + 大小王 + 牌背 `back.png` / `back-blue.png`），四副牌同一套图。

## 1. 风格

| 项 | 规定 |
|---|---|
| 基调 | 青岛老城夏夜：海边石头露台上支一张牌桌，身后是红瓦屋顶、石栏杆、伸进海里的栈桥和尽头的八角小亭，头顶一串灯泡。安静、海风、暖灯。白天版是晴天午后：碧蓝海面、白云、海鸥、米色石板 |
| 光照 | 夜：冷色月光（右上）做环境光，**暖橙灯光是主光**（栏杆柱头灯、灯串、窗户），亮部偏暖、阴影偏蓝。日：太阳在右上，阴影落在左下，整体高明度。所有小图标、徽章统一「左上亮边、右下暗边」 |
| 描边 | 小图（徽章、图标、头像、特效）：完整 1px 深色描边 `#0b1220`（不用纯黑），透明底。场景：不描边，用色块和明暗分体积 |
| 像素密度 | 场景 512×288，整块大色块、少量抖动（有序 4×4 Bayer），细节集中在上半部（海、栈桥、屋顶）；**下半部（牌桌区域）是低对比度的大石板**，不能抢牌面。小图 24×24 / 36×20 / 40×40，一个元素一眼认得出，不堆细节 |
| 构图 | 场景按房间区域等比放大后从中间裁（cover），**左右各 1/8、上下各 1/10 可能被裁掉**，关键景物（栈桥、小亭）放在中间 3/4。上方 1/4 会被对头座位、顶栏压住，中间 1/2 是出牌区 |
| 文字 | 场景、插画、封面里**一个字都不要**（招牌、旗子、啤酒瓶标签也不要字）。徽章、「够级！」这类必须有字的，只由 `art/simple.py` 用 Fusion Pixel 12px（或其 2 倍）画 |
| 不要 | 像国旗的旗帜、知名建筑的写实还原（栈桥和小亭只取「意思」）、啤酒品牌标签、人物脸（场景和封面都不画人）、现代汽车和广告牌、冷蓝光压过暖灯 |

## 2. 牌桌尺寸估算（给界面参考，界面开工时实测为准）

参考斗地主 `apps/web/src/table.ts` 的 `pickLayout`。够级 6 座 + 36 张手牌：

| 区域 | 1440×790（桌面） | 390×664（手机） |
|---|---|---|
| 手牌（按点数分列：3…A 共 12 列 + 2 + 小王 + 大王 = 15 列，同点数叠成一列、列顶显示张数） | 牌 2×（82×114），列宽 82 + 间隔 6 → 15 列约 1320px；加列顶张数，手牌区高约 150px | 牌 1×（41×57），分两行，每行 8 列约 360px，高约 2×(57+20)=154px |
| 6 个座位名牌（自己下方，对头正上方，其余四个在左右上下） | 名牌九宫格放 2×，约 224×96；头像框 2×（96×96）；名次徽章 2×（72×40） | 名牌 1×，约 120×52；头像框 1×（48）；名次用 CSS 文字 ≥12px，或徽章 1× |
| 每人最近一手牌（出牌区） | 1×（41×57），最多约 10 张错开 14px，约 170px 宽 | 1×，只显示「等效牌」读法文字 + 最多 4 张 |
| 状态图标（够级、烧牌中……） | 2×（48×48），挂在名牌边上 | 1×（24×24） |
| 「够级！」提示 | 2×（192×80），出在出牌人和对头之间 | 1×（96×40），字 12px 像素字 + 界面另配 24px 文案 |

- `art/out/preview/table-night-1440.png`、`table-day-1440.png` 是按上面的倍数拼的示意（不是界面，只用来看尺寸和配色）。
- 背景 512×288 在 1440×790 上用 3×（1536×864，cover 裁中间）；1920×960 用 4×；手机用 3× 再裁中间。
